# Car Loan Calculator

A beginner-friendly car loan calculator built with HTML, CSS, and JavaScript.

This project lets users enter a car price, down payment, loan term, and interest rate to estimate:

- Monthly payment
- Total payment
- Total interest

## Live Project Goals

This project was built to practice core front-end development skills and create a portfolio piece that can grow over time.

## Features

- Clean loan calculator form
- Monthly payment calculation
- Total payment calculation
- Total interest calculation
- Validation for invalid inputs
- Error messages for common mistakes
- Support for 0% interest loans

## Built With

- HTML
- CSS
- JavaScript

## How To Use

1. Enter the car price.
2. Enter the down payment.
3. Enter the loan term in months.
4. Enter the annual interest rate.
5. Click `Calculate Payment`.
6. Review the monthly payment, total payment, and total interest.

## Validation Rules

The calculator checks for:

- Car price greater than 0
- Down payment not being negative
- Down payment being less than the car price
- Loan term greater than 0
- Interest rate not being negative
